# 🎌 ANI STORE

**ANI STORE** — учебный многостраничный интернет-магазин аниме-атрибутики, разработанный в рамках лабораторной работы по дисциплине **«Web-программирование»**.

В магазине представлены коллекционные фигурки, одежда и манга по популярным аниме и манге.

---

## ✨ Возможности сайта

- просмотр популярных товаров;
- каталог товаров по категориям;
- поиск по каталогу;
- сортировка товаров;
- фильтрация по категории и цене;
- подробные страницы товаров;
- галерея изображений;
- отображение характеристик товара;
- блок похожих товаров;
- добавление товаров в корзину;
- изменение количества товаров;
- удаление товаров из корзины;
- автоматический расчёт стоимости заказа;
- применение промокода;
- оформление заказа;
- HTML5-валидация форм;
- адаптивная вёрстка.

---

В каталоге представлены три основные категории:

---

## 📱 Адаптивная вёрстка

Сайт адаптирован под основные размеры экранов, указанные в задании:

- **320 px** — мобильные устройства;
- **768 px** — планшеты;
- **1000 px** — десктоп и планшеты в альбомной ориентации;
- **1280 px и более** — большие мониторы.

Для адаптации используются CSS-медиазапросы, Flexbox и Grid Layout.

## 🚀 Локальный запуск

1. Скачать или скопировать папку проекта.
2. Открыть проект в PhpStorm.
3. Открыть файл `index.html`.
4. Запустить страницу в браузере.

Для просмотра сайта также можно открыть `index.html` напрямую через браузер.

## 🎓 О проекте

Проект создан в учебных целях в рамках лабораторной работы по **Web-программированию**.

Основная цель работы — получение навыков переноса графического макета в HTML-разметку, изучение возможностей CSS и нововведений CSS3, разработка веб-страниц под различные размеры экранов и устройства отображения, а также закрепление навыков позиционирования и стилизации элементов страницы.
